Maha Mangalarati Song website update

Included:
- Added a bilingual Kannada/English navigation link for the Maha Mangalarati Song section.
- Embedded the complete 3-page original song PDF directly in the page so visitors can read it on the website without OCR/transcription changes.
- Added a download button immediately below the embedded song. The button downloads the full PDF.
- Included the original PDF asset: banashankari-maha-mangalarati-song.pdf

GitHub Pages instructions:
1. Extract this ZIP.
2. Upload/replace index.html, style.css and language.js in the repository root.
3. Upload banashankari-maha-mangalarati-song.pdf to the same repository root (same folder as index.html).
4. Commit the changes and wait for GitHub Pages to publish.

The live website is not changed automatically by this package.
