# ದೇವಸ್ಥಾನದ ವೆಬ್‌ಸೈಟ್ — ಆರಂಭಿಕ ಆವೃತ್ತಿ

ಈ ಫೋಲ್ಡರ್ ನಿಮ್ಮ ದೇವಸ್ಥಾನದ ವೆಬ್‌ಸೈಟ್‌ನ ಮೊದಲ ಮಾದರಿಯನ್ನು ಒಳಗೊಂಡಿದೆ. ಕೋಡಿಂಗ್ ಅನುಭವವಿಲ್ಲದಿದ್ದರೂ ಇದನ್ನು GitHub Pages ಮೂಲಕ ಉಚಿತವಾಗಿ ಪ್ರಕಟಿಸಬಹುದು.

## ಫೈಲ್‌ಗಳು
- `index.html` — ವೆಬ್‌ಸೈಟ್‌ನ ವಿಷಯ
- `style.css` — ಬಣ್ಣಗಳು, ವಿನ್ಯಾಸ ಮತ್ತು ಮೊಬೈಲ್ ರೂಪ
- `script.js` — ಮೊಬೈಲ್ ಮೆನು ಮತ್ತು ವರ್ಷದ ಸಂಖ್ಯೆ

## ಮೊದಲು ಸರಿಪಡಿಸಬೇಕಾದ ವಿವರಗಳು
1. ದೇವಸ್ಥಾನದ ಅಧಿಕೃತ ಹೆಸರು ಮತ್ತು ಸ್ಥಳದ ಬರವಣಿಗೆಯನ್ನು ದೃಢಪಡಿಸಿ.
2. ದೇವಸ್ಥಾನದ ನಿಜವಾದ ಮುಖ್ಯ ಚಿತ್ರವನ್ನು ಸೇರಿಸಿ.
3. ನಿಖರ ವಿಳಾಸ, ಸಂಪರ್ಕ ಸಂಖ್ಯೆ, ದರ್ಶನ ಸಮಯ ಮತ್ತು ಪೂಜೆಗಳ ವಿವರಗಳನ್ನು ಸೇರಿಸಿ.
4. ಉತ್ಸವದ ದಿನಾಂಕಗಳನ್ನು ಪ್ರಕಟಿಸುವ ಮೊದಲು ಪರಿಶೀಲಿಸಿ.
5. ದೇಣಿಗೆ QR ಕೋಡ್ ಬೇಕಿದ್ದರೆ ಮಾತ್ರ ಸೇರಿಸಿ.

## ದೇವಸ್ಥಾನದ ನಿಜವಾದ ಚಿತ್ರ ಸೇರಿಸುವುದು
1. ದೇವಸ್ಥಾನದ ಚಿತ್ರವನ್ನು `temple.jpg` ಎಂಬ ಹೆಸರಿನಲ್ಲಿ ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಇಡಿ.
2. `index.html` ನಲ್ಲಿ `temple-placeholder` ಇರುವ ಭಾಗವನ್ನು ಚಿತ್ರದ HTML ಮೂಲಕ ಬದಲಾಯಿಸಬೇಕು. ನೀವು ಚಿತ್ರ ಕಳುಹಿಸಿದರೆ ನಾನು ಈ ಬದಲಾವಣೆಯನ್ನು ಮಾಡಿಕೊಡುತ್ತೇನೆ.

## ಉಚಿತವಾಗಿ ಪ್ರಕಟಿಸುವುದು (GitHub Pages)
1. GitHub.com ನಲ್ಲಿ ಖಾತೆ ತೆರೆಯಿರಿ ಅಥವಾ ಸೈನ್ ಇನ್ ಮಾಡಿ.
2. ಹೊಸ repository ರಚಿಸಿ. ಉದಾಹರಣೆಗೆ `hiriyuru-sri-banashankari-temple`.
3. ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿರುವ ಫೈಲ್‌ಗಳನ್ನು repositoryಗೆ upload ಮಾಡಿ.
4. repositoryಯ **Settings → Pages** ತೆರೆಯಿರಿ.
5. **Deploy from a branch** ಆಯ್ಕೆ ಮಾಡಿ, `main` ಮತ್ತು `/ (root)` ಆಯ್ಕೆಮಾಡಿ, Save ಒತ್ತಿರಿ.
6. GitHub ಪ್ರಕಟಣೆ ಮುಗಿಸಿದ ನಂತರ ವೆಬ್‌ಸೈಟ್ ಲಿಂಕ್ ತೋರಿಸುತ್ತದೆ.

ನೀವು ಬಯಸಿದರೆ ಮುಂದಿನ ಹಂತದಲ್ಲಿ ಪ್ರತಿಯೊಂದು ಕ್ಲಿಕ್‌ಗೂ ಮಾರ್ಗದರ್ಶನ ಕೊಡುತ್ತೇನೆ. ಈ ಮಾದರಿಯಲ್ಲಿರುವ ವಿಳಾಸ/ಸಮಯದ ಸೂಚನೆಗಳನ್ನು ನಿಜವಾದ ಮಾಹಿತಿಯಿಂದ ಬದಲಾಯಿಸಿದ ನಂತರವೇ ಸಾರ್ವಜನಿಕರಿಗೆ ಹಂಚಿಕೊಳ್ಳಿ.
