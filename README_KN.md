## வெளியிடுவதற்கு முன் சரிபார்க்கவும் / ಪ್ರಕಟಿಸುವ ಮೊದಲು சரிபார்க்கவும்
- உண்மையான ದೇವಸ್ಥான/தேவி புகைப்படத்தை சேர்க்கவும்.
- ದೇವಸ್ಥಾನದ ನೈಜ ಇತಿಹಾಸ, ದರ್ಶನ ಸಮಯ, ಸೇವೆಗಳ ಪಟ್ಟಿ ಮತ್ತು ಉತ್ಸವದ ದಿನಾಂಕಗಳನ್ನು ಟ್ರಸ್ಟ್ ದೃಢಪಡಿಸಿದ ನಂತರ ಸೇರಿಸಿ.
- ದೇಣಿಗೆ ವ್ಯವಸ್ಥೆ ಬೇಕಿದ್ದರೆ, ಅಧಿಕೃತ ಟ್ರಸ್ಟ್ ವಿವರಗಳನ್ನು ಪರಿಶೀಲಿಸಿ ನಂತರ ಮಾತ್ರ ಸೇರಿಸಿ.
- ಈ ಮಾದರಿಯಲ್ಲಿರುವ ಪೂಜೆ/ಸೇವೆಗಳ ವಿಭಾಗಗಳು ಉದಾಹರಣೆಯಷ್ಟೇ; ದೇವಸ್ಥಾನದಲ್ಲಿ ಅವು ಲಭ್ಯವಿವೆ ಎಂದು ದೃಢೀಕರಿಸುವುದಿಲ್ಲ.

## GitHub Pagesಗೆ ಅಪ್‌ಡೇಟ್ ಮಾಡುವ ವಿಧಾನ
1. ಈ ZIP ಫೈಲ್ ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ Extract ಮಾಡಿ.
2. ನಿಮ್ಮ GitHub repository `HiriyuruBanashankariTemple` ತೆರೆಯಿರಿ.
3. `Add file` → `Upload files` ಆಯ್ಕೆ ಮಾಡಿ.
4. ಹೊಸ `index.html`, `style.css`, `script.js`, `README_KN.md` ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಿ.
5. ಹಳೆಯ ಫೈಲ್‌ಗಳ ಹೆಸರೇ ಇರುವುದರಿಂದ GitHub ಅವುಗಳನ್ನು ಬದಲಾಯಿಸುತ್ತದೆ. `Commit changes` ಒತ್ತಿರಿ.
6. ಕೆಲವು ನಿಮಿಷಗಳಲ್ಲಿ GitHub Pages ಜಾಲತಾಣದಲ್ಲಿ ಬದಲಾವಣೆ ಕಾಣಿಸುತ್ತದೆ.
